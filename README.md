# Proxmox Guides [9.2.25]
Ein paar Proxmox Guides um verschiedenste Dienste in LXC Containern zu installieren.  
Ganz ohne Vorwissen könnten das ein oder andere schwierig sein, aber alles ist möglich, ansonsten kann man ja KI um Hilfe fragen.  
### Code und Befehle befinden sich immer in diesen kopierbaren Fenstern:
```
sudo apt update && sudo apt upgrade -y
```
Für jedes Thema gibt es eine eigene .md Datei.  
Die Guides bauen nicht aufeinander auf, also sucht euch ruhig was aus, man muss nicht alles installieren.  
Also viel Spaß beim basteln und Troubleshooting.
